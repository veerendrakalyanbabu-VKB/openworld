# OpenWorld v0.1.0 — MVP Foundation

## Added
- Complete trust pipeline: identity → policy → risk → approval → execution → verification → audit
- Deterministic policy engine with agent/action/condition matching
- Rule-based risk evaluation with explainable factors
- Registered action executors (email, webhook, API, payment, invoice)
- Human approval workflow with approve/deny
- FastAPI backend with versioned REST API
- Next.js command center UI with dark graphite design system
- Trust Core 3D visualization
- Command palette (Ctrl+K / Cmd+K)
- Intelligence interface with evidence-based queries
- Simulation lab for policy testing
- Python SDK and CLI
- Demo mode with synthetic data
- Docker and CI/CD support
- Comprehensive test suite
